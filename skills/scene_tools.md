# 场景与工具（极简事实：能被探索确认的知识都收敛在这里）

## 坐标系（全局相机在场景一侧俯视；机械爪初始 z≈0.25，桌面 z≈0）
- +x = 靠近相机（画面更靠下）；−x = 远离相机（画面更靠上）。
- +y = 画面更靠右；−y = 画面更靠左。
- +z = 向上；抬高/降低只能用 move ±z。
- 说方位一律给世界轴（+x/−x/+y/−y），不要用「画面左右上下」这类词。

## 工具：一句话说明它适合做什么
- `approach(target, height_offset_cm)`：服务端闭环「对准 + 下降」，停在目标中心上方 height_offset_cm 处；
  要对准某个东西就用它，不要手拼一串 move。
- `move(direction, distance_cm)`：世界轴相对平移；抬高/降低只能靠它。
- `rotate(axis, angle_deg)`：绕世界轴旋转末端姿态。
- `gripper(action)`：`close` 夹住、`open` 松开；结果给指宽（≈0.036 张开 / ≈0.0007 空夹 / 0.02~0.03 指间有物体）。
- `verify(claim)`：只由环境真值回答任务是否完成，不是自我确认。

## 组合：探索一次就该记住
- 抓起：`approach(物体)` → `gripper close`；夹空说明没对准，先 `move +z` 抬起再 approach。
- 放下：**先 `approach(容器, 15)` 到容器开口正上方**，再 `gripper open`；不要用一串 move 凭画面猜位置。
- 容器很浅：`approach(容器, 1~2)` 会直插到容器底部并把容器推走；对准容器一律用 `height_offset_cm≈15`。
- 见到「未到达 / 卡住 / 只走了 X cm」：先 `move +z` 抬起再重新 approach，不要原地重复同一条指令。
- 只有「放进容器」这一步不可逆（放下就拿不回来）；其余动作都能重试，所以宁可多走一步。
