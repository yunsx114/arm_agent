# 场景与工具（极简事实：能被探索确认的知识都收敛在这里）

## 坐标系（全局相机在场景一侧俯视；机械爪初始 z≈0.25，桌面 z≈0）
- +x = 靠近相机（画面更靠下）；−x = 远离相机（画面更靠上）。
- +y = 画面更靠右；−y = 画面更靠左。
- +z = 向上；抬高/降低只能用 move ±z。
- 说方位一律给世界轴（+x/−x/+y/−y），不要用「画面左右上下」这类词。

## 工具：一句话说明它适合做什么
- `approach(target, height_offset_cm)`：服务端闭环「对准 + 下降」，停在目标中心上方 height_offset_cm 处；
  要对准某个东西就用它，不要手拼一串 move。
- `move(direction, distance_cm)`：世界轴相对平移；抬高/降低只能靠它。
- `rotate(axis, angle_deg)`：绕世界轴旋转末端姿态。
- `gripper(action)`：`close` 夹住、`open` 松开；结果给指宽（≈0.036 张开 / ≈0.0007 空夹 / 0.02~0.03 指间有物体）。
- `verify(claim)`：只由环境真值回答任务是否完成，不是自我确认。

## 高度（最容易踩的一条）
- 容器口沿 z≈0.115（桌面 z=0）。
- 手里物体的**中心就在爪心**，物体底部在爪心**下方约 5.4cm**。⇒ 站在容器上方时爪心必须 ≥0.17，
  否则物体底在口沿之下，一横移就撞在容器上把容器推走。抓取高度是 z≈0.05，所以要抬约 +15cm。
- 容器开口是一个 ~16×17cm 的方口，而罐子只有 ~6.6cm 宽。⇒ **夹爪 xy 与开口中心相差 5cm 以内
  就一定落得进去**，不要因为画面里看着「偏一点」就继续挪位置或者拒绝放手。
- 实测（第 14 轮）：爪心 z=0.100 时横移 29cm，把篮子整体推走 12.9cm；之后每次 offset=15
  （爪心 0.145，物体底 0.091）的 `approach(容器)` 又继续往前推，篮子最终跑到 y=0.65 够不着。

## 组合：探索一次就该记住
- 抓起：**先 `gripper open` → `approach(物体)` → `gripper close`**。顺序反了（两指闭合着下降）就是拿
  指尖去顶物体：实测每次下降把罐子推走约 4cm（15 次共 30cm），而且永远夹不住。
- 夹空之后：先 `move +z` 抬起、**再 `open`**，然后重新 `approach`；两指闭着的状态下重复 close 没有意义。
- 抓起后、横移前：**`move +z` 把爪心抬到 ≥0.20**（从抓取高度 0.05 起算约 +15cm）。
- 放下：**爪心 ≥0.20 → `approach(容器, 20)` → `gripper open`**。`approach` 是**先横移、后升降**，
  横移那一段的高度由你调用前的 z 决定，所以要先 `move +z` 抬够再 approach。
  实测：`approach(容器, 20)` 一次就停到开口正上方（xy 误差 ~2mm）；用 move 凑位置的 71 次里只有 2 次
  落在开口矩形内（某轮 19 次全在框外、y 冲过容器 49cm）。
- move 的 x/y 步长是固定几厘米，靠它猜两轴必然「一个轴走对、另一个轴还差几厘米」；发现「差一点」时
  **不要继续 move 微调**，直接 `approach(容器, 20)` 重新对准（它会把两轴一起归位）。
- 容器很浅、也会被动：`approach(容器, 1~2)` 会直插到容器底部并把容器推走；撞过它之后它的位置就
  变了，`approach` 报的「xy 误差 1~2mm」是相对「调用那一刻测到的位置」，不代表现在还在开口正上方。
- 见到「未到达 / 卡住 / 只走了 X cm」：先 `move +z` 抬起再重新 approach，不要原地重复同一条指令。
- `verify` 失败时物体往往还夹在手上：**不要回头去 approach 物体**（指尖会把它刮掉），
  改为 `approach(容器, 20)` 重新对准后放手。
- 只有「放进容器」这一步不可逆（放下就拿不回来）；其余动作都能重试，所以宁可多走一步。
